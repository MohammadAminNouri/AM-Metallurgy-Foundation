# Open-source and public data integrations

## MechProNet-style data
Use for mechanical properties: YS, UTS, elastic modulus, elongation, hardness, roughness.
Check license before redistributing exact data.

## MeltpoolNet
Use for melt-pool geometry, mode, and defect classification.
Suggested ingestion target: `data/external/meltpoolnet/`.

## NIST AM-Bench
Use for rigorous AM benchmark measurements, including process and microstructure measurements.
Suggested ingestion target: `data/external/nist_ambench/`.

## Public melt-pool image compilations
Use for future V4/V5 image modules.

## User data
Users can upload CSV files with the same schema as `data/examples/user_input_template.csv`.
